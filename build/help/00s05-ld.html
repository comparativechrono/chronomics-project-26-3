Two SNPs that travel together are the visible tip of a haplotype block – a whole run of variants inherited as one piece. This is the core of your project: measure the linkage between the two variants properly, then extend it to every variant around them, in the 2,504 genomes of the 1000 Genomes Project, and draw the boundaries of the block.

You will learn
  • linkage disequilibrium, and r² and D′ as measures of it
  • to work with the 1000 Genomes phased panel, and to pick an unrelated subset
  • to correlate every variant in a window with a haplotype, in R
  • that LD is population-specific – and why that matters for a block
Linkage disequilibrium

Every mutation arises on one chromosome, beside the variants that chromosome already carries. Recombination slowly shuffles them, but variants close together are rarely separated and stay together on the same haplotypes for many generations. Variants found together more often than chance are in linkage disequilibrium (LD). Two measures: r² (the squared correlation, 0–1) is high only when two variants have similar frequencies and predict each other; D′ (0–1) is high whenever one allele is found almost only with one allele of the other, even if their frequencies differ. A haplotype block is a run of variants in high mutual LD.

1. The two variants' LD, in 2,504 genomes

The 1000 Genomes file has 3,202 people; 2,504 of them are unrelated – the set to use for LD. Pull the unrelated sample names from the sample table, then extract the two variants' genotypes for them:

cd ~/project
awk -F'\t' 'NR>1 && $6=="yes"{print $1}' /data/examples/scn5a/1000g/1kgp_samples.tsv > results/unrelated.txt
wc -l results/unrelated.txt
bcftools view -S results/unrelated.txt -m2 -M2 -v snps -r chr3:38650537,chr3:38651526 \
  /data/examples/scn5a/1000g/1kgp_scn5a_2Mb.vcf.gz \
  | bcftools query -f '%POS\t%REF\t%ALT[\t%GT]\n' | sed 's/|/\t/g' > results/kgp_two_variants.tsv
awk '{print $1, "columns:", NF}' results/kgp_two_variants.tsv
Check

2,504 unrelated samples, so each variant row has 4 + 5,008 columns. (The 1000 Genomes file is already one allele per line, so you do not need norm here – unlike the pangenome.)

In R, measure r² between the two:

kv <- read.delim("~/project/results/kgp_two_variants.tsv", header = FALSE, na.strings = ".")
hap <- as.matrix(kv[, -(1:3)])                 # one row per variant, one column per haplotype
a <- hap[kv$V1 == 38651526, ]                  # rs41310749-A
b <- hap[kv$V1 == 38650537, ]                  # rs41310239-G
cor(a, b, use = "complete.obs")^2              # r^2, pooled across all 2,504
Check

Pooled across everyone, r² ≈ 0.70. The two variants are in strong LD – but not perfect, and the next sections show why: the LD is very different between populations.

2. Extend to the whole region

Now the real question: which other variants travel with the two-SNP haplotype? LD is strongest within one population, so work within Europeans first (stage 6 compares populations). Extract every biallelic SNP in a 160-kb window, for the unrelated Europeans:

awk -F'\t' 'NR>1 && $6=="yes" && $4=="EUR"{print $1}' /data/examples/scn5a/1000g/1kgp_samples.tsv > results/eur.txt
wc -l results/eur.txt
bcftools view -S results/eur.txt -m2 -M2 -v snps -r chr3:38560000-38720000 \
  /data/examples/scn5a/1000g/1kgp_scn5a_2Mb.vcf.gz \
  | bcftools query -f '%POS\t%REF\t%ALT[\t%GT]\n' | sed 's/|/\t/g' > results/kgp_eur_window.tsv
wc -l results/kgp_eur_window.tsv
Check

About 503 unrelated Europeans, and roughly 3,300 SNPs in the 160-kb window.

In R, build the two-SNP haplotype in this group and correlate every SNP with it:

w <- read.delim("~/project/results/kgp_eur_window.tsv", header = FALSE, na.strings = ".")
pos <- w$V1; alt <- w$V3
G <- as.matrix(w[, -(1:3)])                    # SNPs x haplotypes
a <- G[pos == 38651526 & alt == "A", ]
b <- G[pos == 38650537 & alt == "G", ]
both <- as.integer(a == 1 & b == 1)            # the two-SNP haplotype, in Europeans
mean(both)                                      # its frequency here
r2 <- apply(G, 1, function(x) suppressWarnings(cor(x, both, use = "complete.obs"))^2)

apply(G, 1, …) runs the correlation for every row (SNP). Now find the block – the SNPs in high LD with the haplotype:

block <- pos[!is.na(r2) & r2 >= 0.8]
length(block)                                   # how many SNPs
range(block)                                    # the block's edges
(max(block) - min(block)) / 1000                # its width in kb
Check

In Europeans the two variants have r² = 1.0 with each other (the two-SNP haplotype is at ~16% here). Around 20 SNPs reach r² ≥ 0.8 with the haplotype, spanning chr3:38,631,501–38,682,101 – a block of about 50 kb. This is the larger haplotype your project set out to find. It runs from inside SCN5A, across the promoter, into the gap before SCN10A.
