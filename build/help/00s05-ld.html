Linkage disequilibrium

Every mutation arises on one chromosome, beside the variants that chromosome already carries. Recombination slowly shuffles them, but variants close together are rarely separated and stay together on the same haplotypes for many generations. Variants found together more often than chance are in linkage disequilibrium (LD). Two measures: r² (the squared correlation, 0–1) is high only when two variants have similar frequencies and predict each other; D′ (0–1) is high whenever one allele is found almost only with one allele of the other, even if their frequencies differ. A haplotype block is a run of variants in high mutual LD – and because the pangenome gives you whole phased chromosomes, you can see it directly.

1. The two variants, in the pangenome's phased haplotypes

You already have the two-SNP haplotype from stage 4 (your 462 pangenome haplotypes, 40 carrying both). Load your stage 5 notebook and rebuild the two variants' rows:

tv <- read.delim("~/project/results/hprc_two_variants.tsv", header = FALSE, na.strings = ".")
samples <- readLines("~/project/results/hprc_samples_order.txt")
hap_names <- paste0(rep(samples, each = 2), "_hap", 1:2)
colnames(tv) <- c("pos", "rsid", "ref", "alt", hap_names)
a <- as.integer(tv[tv$rsid == "rs41310749", hap_names])
b <- as.integer(tv[tv$rsid == "rs41310239", hap_names])
cor(a, b, use = "complete.obs")^2      # r^2 between the two variants, read off phased haplotypes
Check

r² ≈ 0.63 between the two variants in the 462 pangenome haplotypes. No statistical phasing was needed – each chromosome was assembled whole, so the haplotypes are read directly.

2. Extend to the block – every variant, indels and all

Now the real question: which other variants travel with the two-SNP haplotype? Pull every variant of the locus from the pangenome – SNPs and insertions and deletions – using the split file you made in stage 3, and build a table across a window around the promoter:

cd ~/project
bcftools view -r chr3:38600000-38700000 results/hprc_split.vcf.gz \
  | bcftools query -f '%POS\t%REF\t%ALT[\t%GT]\n' | sed 's/|/\t/g' > results/hprc_window.tsv
wc -l results/hprc_window.tsv

In R, build the two-SNP haplotype and correlate every variant with it. The rows that are not single-letter changes are the indels – the ones short reads struggle to call:

w <- read.delim("~/project/results/hprc_window.tsv", header = FALSE, na.strings = ".")
pos <- w$V1; ref <- w$V2; alt <- w$V3
G <- as.matrix(w[, -(1:3)])
a2 <- G[pos == 38651526 & alt == "A", ]; b2 <- G[pos == 38650537 & alt == "G", ]
both <- as.integer(a2 == 1 & b2 == 1)                 # the two-SNP haplotype, in the pangenome
sum(both, na.rm = TRUE)                               # carriers
r2 <- apply(G, 1, function(x) suppressWarnings(cor(x, both, use = "complete.obs"))^2)
is_indel <- nchar(ref) != nchar(alt)
block <- which(!is.na(r2) & r2 >= 0.8)
length(block); range(pos[block]); (max(pos[block]) - min(pos[block])) / 1000   # size in kb
data.frame(pos = pos[block], ref = substr(ref[block],1,10), alt = substr(alt[block],1,10),
           type = ifelse(is_indel[block], "indel", "SNV"), r2 = round(r2[block], 2))
Check

40 carriers. The pangenome block (r² ≥ 0.8) is 12 variants over ~31.6 kb (chr3:38,650,537–38,682,101), and two of them are indels – an 8-bp deletion at 38,679,353 and a 1-bp deletion at 38,680,173 (both r² = 0.84). You have read a haplotype block, structural variants included, straight from complete genomes. The block runs from the promoter into the gap before SCN10A.

Why this needed the pangenome

A block defined only from SNPs is missing part of the story. Insertions and deletions in LD with your haplotype are part of it – and they are exactly what short-read sequencing calls badly, especially in repetitive DNA. Because the pangenome assembled every genome in full, those indels are in your table with everything else, and you could tell they travel with the haplotype.

3. Read the actual sequence of a carrier haplotype

In stage 2 you saw that rs41310239 sits in an awkward CG-repeat. The pangenome can rebuild the real sequence of any haplotype through it, with bcftools consensus. Compare a carrier with a non-carrier:

samtools faidx /data/examples/scn5a/reference/GRCh38_chr3_SCN5A.fa.gz chr3:38650480-38650600 > results/patch.fa
echo "REFERENCE  "; grep -v "^>" results/patch.fa | tr -d '\n' | cut -c41-95; echo
echo "HG00097 h1 (non-carrier)"; bcftools consensus -f results/patch.fa -s HG00097 -H 1 results/hprc_split.vcf.gz 2>/dev/null | grep -v "^>" | tr -d '\n' | cut -c41-95; echo
echo "HG00133 h1 (carrier)     "; bcftools consensus -f results/patch.fa -s HG00133 -H 1 results/hprc_split.vcf.gz 2>/dev/null | grep -v "^>" | tr -d '\n' | cut -c41-95; echo
Check

The reference and the non-carrier (HG00097) read …CACCCACACACGCGCGCGCG…; the carrier (HG00133) reads …CACCCACACGCGCGCGCGCG… – the derived allele turns the A into a G and so lengthens the run of CG. You have reconstructed a real human haplotype's promoter sequence, base by base, through a repeat that short reads cannot phase. (If HG00133 is not a carrier in your data, pick one: sub("_hap1$", "", hap_names[which(both == 1)][1]).)

4. Confirm and sharpen it in 1000 Genomes

The pangenome gave you the block from 231 people; the 1000 Genomes Project has 3,202 (2,504 unrelated), so it can place the edges more precisely. LD is strongest within one population, so work within Europeans (stage 6 compares populations). Extract every biallelic SNP in the window for the unrelated Europeans:

awk -F'\t' 'NR>1 && $6=="yes" && $4=="EUR"{print $1}' /data/examples/scn5a/1000g/1kgp_samples.tsv > results/eur.txt
bcftools view -S results/eur.txt -m2 -M2 -v snps -r chr3:38560000-38720000 \
  /data/examples/scn5a/1000g/1kgp_scn5a_2Mb.vcf.gz \
  | bcftools query -f '%POS\t%REF\t%ALT[\t%GT]\n' | sed 's/|/\t/g' > results/kgp_eur_window.tsv
wc -l results/eur.txt results/kgp_eur_window.tsv
e <- read.delim("~/project/results/kgp_eur_window.tsv", header = FALSE, na.strings = ".")
epos <- e$V1; ealt <- e$V3; E <- as.matrix(e[, -(1:3)])
ea <- E[epos == 38651526 & ealt == "A", ]; eb <- E[epos == 38650537 & ealt == "G", ]
eboth <- as.integer(ea == 1 & eb == 1)
cor(ea, eb, use = "complete.obs")^2                   # r^2 between the two variants, in Europeans
er2 <- apply(E, 1, function(x) suppressWarnings(cor(x, eboth, use = "complete.obs"))^2)
eblock <- epos[!is.na(er2) & er2 >= 0.8]
length(eblock); range(eblock); (max(eblock) - min(eblock)) / 1000
write.csv(data.frame(pos = epos, alt = ealt, r2 = er2), "~/project/results/ld_eur.csv", row.names = FALSE)
Check

In Europeans the two variants have r² = 1.0 with each other, and about 20 SNPs reach r² ≥ 0.8 with the haplotype, spanning chr3:38,631,501–38,682,101 (~50.6 kb). The 1000 Genomes data confirm the pangenome block and sharpen its edges: same upper boundary near SCN10A, a cleaner lower edge inside SCN5A. Two methods, two very different datasets, one block.
