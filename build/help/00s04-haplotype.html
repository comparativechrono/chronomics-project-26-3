Stage 4 · The two-SNP haplotype

Week 4about 5 hours

Park et al. (2012) said the minor alleles of the two variants "travel together". Now you can see it for yourself, in 462 complete genomes. This is your first stage in R: you will read the table you made, build the haplotype of both variants, and count how often each combination occurs.

1. Open your stage 4 notebook

This makes an R notebook in ~/notebooks. Add each code box below to it with Add to notebook, and run the cell with Shift+Enter. Write what you find in text cells as you go.

2. Read the table and name the haplotypes

The table has one row per variant and one column per haplotype, in the order of the samples (two haplotypes each). Read it, and build the haplotype names:

tv <- read.delim("~/project/results/hprc_two_variants.tsv", header = FALSE, na.strings = ".")
dim(tv)
samples <- readLines("~/project/results/hprc_samples_order.txt")
hap_names <- paste0(rep(samples, each = 2), "_hap", 1:2)
length(hap_names)
# the 4 label columns, then one column per haplotype
colnames(tv) <- c("pos", "rsid", "ref", "alt", hap_names)
tv[, 1:8]
Check

tv has 2 rows and 466 columns; hap_names has 462 entries, like HG00438_hap1, HG00438_hap2, …

3. Pull out each variant as a row of 0s and 1s

a <- as.integer(tv[tv$rsid == "rs41310749", hap_names])   # 1 = the A allele
b <- as.integer(tv[tv$rsid == "rs41310239", hap_names])   # 1 = the G allele
mean(a, na.rm = TRUE)      # frequency of rs41310749-A
mean(b, na.rm = TRUE)      # frequency of rs41310239-G
Check

rs41310749-A is on about 0.121 of the 462 haplotypes; rs41310239-G on about 0.093.

4. Do they travel together?

Cross-tabulate the two variants: how many haplotypes carry each combination?

table(rs41310749_A = a, rs41310239_G = b)
Check

Of 462 haplotypes: 403 carry neither minor allele, 40 carry both, 16 carry only rs41310749-A, and 3 carry only rs41310239-G. The two minor alleles are almost always together – just as Park et al. described. Nearly every rs41310239-G chromosome (40 of 43) also carries rs41310749-A.

The two-SNP haplotype – both minor alleles – is a row of its own, 1 where a haplotype carries both:

both <- as.integer(a == 1 & b == 1)
mean(both, na.rm = TRUE)         # frequency of the two-SNP haplotype
sum(both, na.rm = TRUE)          # how many haplotypes carry it
write.csv(data.frame(haplotype = hap_names, rs41310749_A = a, rs41310239_G = b, two_snp = both),
          "~/project/results/hprc_haplotypes.csv", row.names = FALSE)
Check

The two-SNP haplotype is on about 0.087 of haplotypes (40 of 462). You have just measured, in complete genomes, the haplotype Park et al. inferred from families.
